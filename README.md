# AI-Receipt-Scanner-Mobile-Application

A smart mobile application that uses AI to simplify receipt management. User can capture receipts using their camera or upload images from their gallery. The app automatically extracts key details using AI-powered image processing. Built with React Native and Expo, it offers a user-friendly interface that makes receipt scanning quick and efficient. AI-powered framework intelligently detects the currency used in each receipt and accurately extracts information even from damaged, blurry or faded text, ensuring reliable receipt processing under challenging image conditions.
